# Australian school comparison — Phase 4 profile and plan

Date: 25 September 2026. Baseline: sitecomms-au-phase-3-finance-2026-09-23.zip.
Authorised scope: local code/content changes and non-destructive tests; no deployment, indexing changes, leads or live provider contact.

## Observed baseline
The school comparison is currently served at /compare. Its seven main records exclude SPON, which is a conditional specialist. Pages render shared school-compare.ts records; Agent-Ready guide search uses the public guide directory. Funding, finance and pricing have their own handlers. /compare/schools does not yet exist.

## Proposed, approved scope
Reuse the Australian theme, server-rendered content components, source registry, metadata helpers, existing enquiry launcher and state-aware links.
Refactor the comparison into the canonical /compare/schools, with a permanent /compare alias and retained fragment targets.
Expand the shared comparison records to include SPON as an all-round school option. No numeric ranking, lowest-price claim, fictional Australian distributor, verified deployment or endorsement.
Add use-case shortlists, comparable capability fields, cost/scope discussion, published Australian examples/reference routes, source limits and a direct reviewed-enquiry handoff.
Defer funding/finance changes, aged-care comparison, model tools, new protocols, automatic leads and design-system changes.

## Authorities
Manufacturer product/technical pages: specified capabilities, not installed performance.
Australian manufacturer/distributor/provider pages: published commercial enquiry routes, not stock, national installer coverage or SiteComms partnerships.
Named integrator case studies: attributed published project descriptions, not independent testing.
SiteComms: editorial selection, buying questions and illustrative project scenarios, not quotes.
The NZ comparison is a UX reference only. Its supplier facts and favourable ratings are not evidence for Australia.
